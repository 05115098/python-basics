# Python Basics

A beginner-friendly Python learning project demonstrating fundamental Python programming concepts, a simple calculator, and automated unit testing.

## Project Structure

```text
01_Python_Basics/
├── hello.py
├── calculator.py
├── test_calculator.py
├── .gitignore
└── README.md
```

## Features

- Basic Python syntax and variables
- NumPy array operations
- A calculator supporting addition, subtraction, multiplication, and division
- Error handling for division by zero and unsupported operators
- Automated unit tests using Python's built-in `unittest` framework

## Requirements

- Python 3
- NumPy

## Getting Started

Clone the repository:

```bash
git clone https://github.com/05115098/python-basics.git
cd python-basics
```

Install NumPy:

```bash
python -m pip install numpy
```

Run the basic Python example:

```bash
python hello.py
```

Run the calculator:

```bash
python calculator.py
```

## Running Tests

Run the automated unit tests:

```bash
python -m unittest test_calculator.py -v
```

The test suite covers basic arithmetic operations and error handling.
